# `i18n` — localization messages

Generic module, one file: `en.json`. The single message catalog for the whole application.

> **This module has a dedicated deep-dive: [i18n](../i18n.md).** This page is orientation only.

No `ModuleRegistrar` and no injectable service — components use `useI18n()` from `vue-i18n`, and code
outside component setup uses `i18n.global.t`.

## Conventions

- **Every user-facing string** goes through the catalog. No literals in components.
- Keys are **namespaced by module**, mirroring the module name
  (`trafficViewer.recordHistory.button.…`, `taskViewer.tasksVisualizer.…`).
- Within a module, the conventional groups are `title`, `button`, `form`, `info`, `notification`,
  `list`, `validations`.
- Interpolation uses named params (`{catalogName}`, `{reason}`); plurals use vue-i18n's
  `no records | 1 record | {count} records` form.

## The `useI18n()` trap

`useI18n()` throws outside a component `setup()`. Model classes, services and getters
(e.g. `representativeFlags` in [`database-driver`](database-driver.md)) must use `i18n.global.t`
instead. This is a recurring review point.
